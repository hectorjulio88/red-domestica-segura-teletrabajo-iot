# Guía básica de segmentación de red doméstica mediante VLAN

Manual práctico de referencia para separar una red en tres entornos: Trabajo, Personal e IoT.

El documento incluye ejemplos de comandos Cisco IOS para:
- Crear VLAN en un switch.
- Asignar puertos de acceso.
- Configurar enlaces troncales.
- Configurar subinterfaces y direccionamiento IP en un router.
- Crear pools DHCP.
- Aplicar políticas básicas mediante ACL.
- Verificar la configuración.

**Importante:** los números de VLAN, direcciones IP, interfaces y puertos son ejemplos. Deben adaptarse al equipo y a la topología que se vaya a implementar. La sintaxis puede variar según el modelo y la versión del sistema operativo.
